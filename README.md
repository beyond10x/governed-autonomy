# Governed Autonomy

The public page for Beyond10x Governed Autonomy: give autonomous agents real responsibility while
the organization keeps control over what they may do, what they must prove, and when work is
actually complete.

**From intent to verified outcome.**

Live at <https://beyond10x.github.io/governed-autonomy/>.

## Layout

| path | what |
|---|---|
| `site/` | the web page: `index.html`, `styles.css`, `case.js` (hero animation), `assets/` |
| `.github/workflows/pages.yml` | publishes `site/` to GitHub Pages on every push to `main` |

## View it locally

Open `site/index.html` in a browser. There is no build step.
